# Introduction & How to Use This Course

Welcome! This space will host your Java + Spring Boot learning notes and blog posts.

Tips:
- Use the left search box to quickly filter topics by title.
- Use the Previous/Next buttons at the bottom to navigate linearly.
- You can write posts in Markdown: create new files under `src/modules/java/content/` and reference them via `mdPath` in `javaData.tsx`.
